# Evan Bacon

Building [Expo](https://expo.dev). Follow me on [X](https://x.com/baconbrix) for updates.

## Open Source Projects

### Expo

- **[expo](https://github.com/expo/expo)** — The universal React framework
- **[bun create target](https://github.com/EvanBacon/expo-apple-targets)** — Apple multi-target from the command-line (Widgets, App Clips, +43 more)
- **[expo-quick-actions](https://github.com/EvanBacon/expo-quick-actions)** — Home screen shortcuts and dynamic icons, one API for iOS and Android
- **[Expo MDX](https://github.com/EvanBacon/expo-mdx)** — MDX that runs everywhere: iOS, Android, and web
- **[apple-health](https://github.com/EvanBacon/apple-health)** — Apple HealthKit bindings for Expo
- **[expo-ahap](https://github.com/EvanBacon/expo-ahap)** — Play Apple haptic patterns (AHAP) from React Native
- **[Apple colors for Expo](https://github.com/EvanBacon/expo-apple-colors)** — Apple's dynamic system colors on every platform
- **[crispy](https://github.com/EvanBacon/crispy)** — Drop-in UI primitives for Expo Router apps
- **[metro-minify-esbuild](https://github.com/EvanBacon/metro-minify-esbuild)** — Drop-in ESBuild minifier for Metro — dramatically faster bundles

### Apple ecosystem

Tools for building better Apple software.

- **[serve-sim](https://github.com/EvanBacon/serve-sim)** — `npx serve` but for iOS Simulators
- **[xcode](https://github.com/EvanBacon/xcode)** — Blazing fast .pbxproj parser in pure TypeScript
- **[inspect-webkit](https://github.com/EvanBacon/inspect-webkit)** — Inspect iOS Safari and WebViews from Chrome DevTools
- **[bun create xcode](https://github.com/EvanBacon/create-xcode)** — Spin up Xcode projects from the command-line, agent-ready
- **[bun create symbol](https://github.com/EvanBacon/create-symbol)** — Create SF Symbols from the command-line

### Apps & Demos

- **[Crossy Road](https://github.com/EvanBacon/Expo-Crossy-Road)** — Crossy Road clone in the browser and mobile with three.js
- **[Generative mobile chatbot](https://github.com/EvanBacon/expo-ai)** — Full-stack AI chatbot that generates rich native UI cards on edge-servers. Showcase app for React Server Component for React Native. Runs on iOS, Android, and web.
- **[Server-driven UI Google Home client](https://github.com/EvanBacon/expo-router-google-home)** — Google Home client with WebRTC, React Server Components, and Expo DOM components. Tests complex authentication with universal React Server Components on web and native.
- **[Pillar Valley](https://github.com/EvanBacon/pillar-valley)** — 3D arcade game you can play on any device. Used to dogfood edge-cases in Expo.
- **[Expo Movies app](https://github.com/EvanBacon/expo-rsc-movies)** — Movie search powered by React Server Components in Expo Router
- **[Expo x shadcn](https://github.com/EvanBacon/expo-dom-components-example)** — Shadcn components running in Expo DOM Components with 'use dom'. Mixes native APIs with popular web components.

## Examples

- **[Expo chat-template](https://github.com/EvanBacon/chat-template)** — Universal chatbot template built with Expo Router. Used for training and evals.
- **[app that builds apps](https://github.com/EvanBacon/app-that-builds-apps)** — LLM chatbot app that can generate React Native components, bundle them, then evaluate in-app/website.
- **[expo-router-layouts-example](https://github.com/EvanBacon/expo-router-layouts-example)** — Shared layouts and nested navigation patterns in Expo Router
- **[expo-router Spotify client](https://github.com/EvanBacon/expo-router-spotify)** — Spotify client built with universal React Server Components
- **[expo-router Twitter](https://github.com/EvanBacon/expo-router-twitter)** — Twitter rebuilt with Expo Router. First public example of Expo Router for a moderate layout.
